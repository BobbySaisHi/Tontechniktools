# Mikrofon im Schallfeld

(Repository: Audiotools – Nahfeld & Fernfeld)

Interaktives Lehr-Tool für Tonstudiotechnik: von der Kugelwelle über Druck und Schnelle
zum Nahbesprechungseffekt und zur Höhenentzerrung von Mikrofonen.

## Versionen

- `index.html` – ausführliche Version mit drei Ansichten
- `nahfeld-fernfeld-simplified/index.html` – vereinfachte Version für Einsteiger: nur Klang über Abstand (siehe [README](nahfeld-fernfeld-simplified/README.md))

## Benutzung

`index.html` im Browser öffnen – keine Installation, keine externen Abhängigkeiten.
Läuft auch über GitHub Pages und lässt sich in Moodle verlinken.

## Tests

Beim Laden der Seite laufen die Plausibilitätstests der Physik automatisch und erscheinen
in der Browser-Konsole (F12). Manuell erneut: `runPhysicsTests()` in der Konsole aufrufen.
