Parameter von Schallwellen

Schallgeschwindigkeit (c)

ca. 340 m/s (in Luft)

Periodendauer (T)

Zeitlicher Abstand zwischen zwei gleichen Schwingungszuständen [s]

Frequenz (f)

Anzahl der Schwingungen pro Sekunde [Hz]. 1 Hz = 1 Schwingung/s.

$$f = \dfrac{1}{T}$$

Laufzeit (t)

Zeit, die eine Schallwelle für eine Strecke benötigt (d = Distanz [m], c = Schallgeschwindigkeit [m/s]).

$$t = \dfrac{d}{c}$$

Wellenlänge (λ)

Wellenlänge [m] = Schallgeschwindigkeit / Frequenz

$$\lambda = \dfrac{c}{f}$$

Amplitude

Beschreibt die maximale Auslenkung einer Welle.
